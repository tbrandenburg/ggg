# References and provenance

This repository was informed by these projects. The included launcher, games, tooling, and SVG artwork were implemented from scratch; no source code or assets were copied from these repositories.

| Reference | Idea studied |
| --- | --- |
| [MrEliptik/game_launcher](https://github.com/MrEliptik/game_launcher) | Per-folder discovery, thumbnail metadata, separate game processes |
| [ChristianD37/Godot-Gadget-Games](https://github.com/ChristianD37/Godot-Gadget-Games) | Discoverable game modules and small framework interfaces |
| [godotengine/godot-demo-projects](https://github.com/godotengine/godot-demo-projects) | Independent project folders and focused examples |
| [godotlauncher/launcher](https://github.com/godotlauncher/launcher) | Project and engine lifecycle management |
| [GDQuest/learn-gdscript](https://github.com/GDQuest/learn-gdscript) | Small programming exercises followed by real projects |
| [abarichello/godot-ci](https://github.com/abarichello/godot-ci) | Repeatable headless export workflows |

The Gadget Games repository had no detected license when reviewed, so its code was not incorporated. The other projects' licenses apply to their own content, not this original implementation.

Godot is a separate MIT-licensed engine with third-party components. Official engine/export distributions carry their notices; consult [Godot's license guidance](https://godotengine.org/license/) when distributing games.
